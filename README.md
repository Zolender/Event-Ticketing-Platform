# Event Ticketing Platform

An event ticketing platform in two independent Next.js applications, side by side in one
repository:

| Folder | What it is |
| --- | --- |
| `events-public/` | The public site: browse events and read event details |
| `events-organiser/` | The organiser app: sign in and manage your own events |
| `supabase/` | The database both apps rely on: schema, access policies, seed data, tests |

The reasoning behind the setup is in [DECISIONS.md](DECISIONS.md).
